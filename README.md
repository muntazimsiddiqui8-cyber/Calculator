# 🧮 Calculator

A simple, responsive web calculator built with HTML, CSS, and JavaScript — great for learning or quick demos. ✨

## ✅ Features
- ➕➖✖️➗ Basic arithmetic (add, subtract, multiply, divide)  
- 🔢 Decimal support  
- C (Clear) and ⌫ (Delete last) controls  
- ⌨️ Keyboard support (numbers, operators, Enter = equals, Backspace = delete)  
- 📱 Responsive layout for desktop and mobile

## 🌐 Demo
Open the project by opening `index.html` in your browser 🚀

## ⚡ Quick start (simple)
1. Clone the repo:
   ```bash
   git clone https://github.com/muntazimsiddiqui8-cyber/Calculator.git
   cd Calculator
   ```
2. Open `index.html` in your web browser

## 🧭 Usage
- Click numbers and operators to build an expression.  
- Press "=" or Enter to evaluate. ✅  
- Press "C" to clear everything. 🧹  
- Press "DEL" to delete the last character. ⤵️

## 📁 Project structure
- index.html — main HTML file  
- styles.css — styles and responsive layout 🎨  
- script.js — calculator logic and event handling ⚙️
